### 2. КАКИЕ ФУНКЦИИ ДОБАВЛЕНЫ

- `TextureManager.get(key)`: получение загруженного объекта изображения текстуры из кэша.
- `TextureManager.getFallback(key)`: получение RGB-цвета для бесшовного фоллбека.
- `TextureManager.getRoomMaterial(roomType)`: детерминированное сопоставление типа помещения с материалом стен.
- `TextureManager.getFloorMaterial(roomType)`: сопоставление типа помещения с материалом пола.
- Расчёт `wallX` / `texX` в `renderFPS`: точное текстурирование без смещений и растяжений.
- Анимация `openProgress` гермодверей в `update()`: плавное открытие за 12 кадров.

### 3. КАК ПОДКЛЮЧАЮТСЯ ТЕКСТУРЫ

1. При инициализации `TextureManager` предзагружает все 14 текстур из `assets/radar/tiles/`.
2. В процессе трассировки луча в `renderFPS`, когда DDA-алгоритм находит столкновение со стеной `(mapX, mapY)`:
   - Если это гермодверь (`hitTile === 2`), выбирается текстура `door_blast`.
   - Иначе берётся материал из сетки уровня: `this.mapData.wallMaterials[mapY][mapX]`.
3. По перпендикулярной дистанции `perpDist` вычисляется точная точка удара `wallX = (coord / TS) + perpDist * dir` и нормализуется в диапазон `[0.0 .. 1.0)`.
4. Из текстуры вырезается вертикальная колонка шириной 1 пиксель:
   ```javascript
   ctx.drawImage(texImg, texX, 0, 1, texH, screenX, drawStart, colStep, drawEnd - drawStart);
   ```
5. Поверх накладывается слой затенения по дистанции `rgba(1, 8, 4, 1 - shade)`.

### 5. КАКИЕ ПРОБЛЕМЫ ОБНАРУЖЕНЫ И РЕШЕНЫ

1. **Отсутствие текстурных координат в исходном рейкастере:**
   - *Проблема:* Исходный код рисовал стены сплошными прямоугольниками `ctx.fillRect`.
   - *Решение:* Внедрена классическая формула DDA `wallX = coord + perpDist * rayDir` с зеркалированием для обратных граней (`cos > 0`, `sin < 0`).
2. **Возможность падения при задержке загрузки изображений:**
   - *Проблема:* Если текстура ещё не загрузилась, `drawImage` мог вызвать исключение или мигание.
   - *Решение:* Создана проверка `texImg.complete && texImg.naturalWidth > 0` с автоматическим запасным рендером процедурного цвета материала.
3. **Статичные двери:**
   - *Проблема:* Двери исчезали мгновенно при открытии.
   - *Решение:* Добавлен расчёт `openProgress` со сдвигом текстуры створки, создающим эффект раздвигания бронеплиты.

### 6. РЕЗУЛЬТАТЫ ПРОВЕРКИ ПРОИЗВОДИТЕЛЬНОСТИ

- Замер времени кадра DDA Raycaster с `colStep = 2`: **0.39 – 0.65 мс** на кадр.
- Стабильный фреймрейт: **60 FPS** при разрешении Canvas.
- Z-Buffer полностью сохранен — монстры, сундуки и лут корректно отсекаются стенами и дверьми.
- Режим TDS (вид сверху) и FPS (от первого лица) мгновенно переключаются по клавише `G`.

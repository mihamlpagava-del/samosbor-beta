### 1. ТЕКУЩЕЕ СОСТОЯНИЕ RAYCASTER (G-MODE)

1. **Реализация DDA Raycaster:**
   - Расположение: метод `renderFPS(ctx, w, h)` в `public/assets/radarRoguelike.js` (строки 2050–2307).
   - Алгоритм: Классический Digital Differential Analysis (DDA) по 2D сетке тайлов (`TS = 32`).
   - Шаг трассировки колонок: `colStep = 2` (высокая детализация, `numCols = Math.ceil(w / 2)`).
   - Угол обзора: `fov = 1.15` рад (~66°).
   - Расчёт глубины: перпендикулярная дистанция `perpDist` с коррекцией рыбьего глаза `distCorrection = Math.cos(rayAngle - pAngle)`.
   - Z-Buffer: одномерный массив `Float32Array(numCols)`, хранящий евклидово расстояние в пикселях (`perpDist * TS`) для отсечения биллбордов (монстров, сундуков, оружия, союзников).

2. **Ограничения текущей отрисовки стен:**
   - Стены рендерятся **сплошными однотонными прямоугольниками**:
     ```javascript
     ctx.fillStyle = `rgb(${r}, ${g}, ${b})`;
     ctx.fillRect(screenX, drawStart, colStep, drawEnd - drawStart);
     ```
   - Отсутствует текстурирование стен (`drawImage` не используется).
   - Расчёт координаты попадания по поверхности стены (`wallX` / `texU`) не производился.
   - Пол и потолок рисуются двумя плоскими градиентами `createLinearGradient` (черно-зеленая гамма) без текстур материалов.
   - Двери отличаются от стен только желто-янтарным цветом заливки (`hitTile === 2`).

### 3. МАТЕМАТИЧЕСКАЯ МОДЕЛЬ ИНТЕГРАЦИИ ТЕКСТУР В DDA

Для наложения текстур на стены без искажений вычисляется точная точка удара луча:
1. **Координата `wallX` (от 0.0 до 1.0):**
   ```javascript
   let wallX;
   if (side === 0) {
     wallX = (py / TS) + perpDist * sin;
   } else {
     wallX = (px / TS) + perpDist * cos;
   }
   wallX -= Math.floor(wallX);
   ```
2. **U-координата текстуры (`texX`):**
   ```javascript
   let texX = Math.floor(wallX * texWidth);
   if (side === 0 && cos > 0) texX = texWidth - texX - 1;
   if (side === 1 && sin < 0) texX = texWidth - texX - 1;
   ```
3. **Отрисовка полосы через `CanvasRenderingContext2D.drawImage`:**
   ```javascript
   ctx.drawImage(
     textureImage,
     texX, 0, 1, texHeight,             // Source 1px column
     screenX, drawStart, colStep, lineH // Destination on screen
   );
   ```
4. **Затемнение по дистанции (Distance Fog & Shading):**
   - Расчёт множителя освещённости: `shade = Math.max(0.05, Math.min(1.0, 1.0 - perpDist / maxDist))`.
   - Затемнение теневых сторон: стены по оси Y получают коэффициент `0.75` для объёмности углов.
   - Сверхбыстрое затенение в Canvas 2D: после отрисовки полосы (или группы полос) накладывается полупрозрачный оверлей `rgba(0, 5, 2, 1 - shade)`.

### 5. МОДЕРНИЗАЦИЯ ГЕРМОДВЕРЕЙ

1. **Текстура:** Использование броневого полотна с предупреждающей маркировкой и центральным ригельным замком.
2. **Световая индикация:**
   - Зелёный свет (`#1fe044`) при открытии и в открытом состоянии.
   - Мигающий красный/янтарный (`#ff3b30` / `#ffaa00`) при закрытой двери или опасности Самосбора.
3. **Анимация скольжения:** При открытии двери текстура сдвигается пропорционально `door.openProgress`, плавно открывая проход в помещение.

### 6. СТРАТЕГИЯ ПРОИЗВОДИТЕЛЬНОСТИ

- Предварительная загрузка и кэширование текстур в памяти (`TextureManager`).
- Кэш предзатенённых вариантов или использование эффективного батчинга полос с одинаковым затенением.
- Использование `colStep = 2` для баланса 60 FPS и чёткости геометрии.
- Сохранение полной целостности Z-буфера для корректного отображения монстров перед/за стенами.
